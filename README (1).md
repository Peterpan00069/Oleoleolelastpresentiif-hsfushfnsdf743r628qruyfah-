Página sorpresa (un solo archivo `index.html`).

## Subir a GitHub Pages
1. Crea un repositorio nuevo y sube `index.html` y `.nojekyll`.
2. Settings → Pages → Branch `main` / root → Save.
3. Comparte el enlace `https://TU_USUARIO.github.io/NOMBRE_REPO/` (o un QR).

Se abre el 28/10/2026 a las 20:00 (Madrid). Para probar antes: añade `#probar` al final del enlace.

Respuestas: poner la URL de Formspree en `const ENDPOINT=''` dentro del script.
